# Tauri Desktop Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a native Linux desktop app (Tauri) that opens the existing
production screen-share site in a native window, with a system tray icon
that lets the app keep running (and keep any active screen share alive)
after the window is closed.

**Architecture:** A new, independent Cargo project at `desktop/src-tauri/`
— not a workspace member of the root crate, no shared code with it. The
Tauri window's webview loads `https://screen-share-h0rb5w.fly.dev/`
directly as an external URL; no web assets are embedded or built locally.
All native behavior (tray icon, menu, close-to-hide) lives entirely in
`desktop/src-tauri/src/main.rs`.

**Tech Stack:** Tauri v2 (`tauri` crate with the `tray-icon` and
`image-png` features), `tauri-build`, the `tauri-cli` (`cargo tauri`
subcommand). Linux only (WebKitGTK) for this plan.

## Global Constraints

- The root crate (`screen-share`, at the repo root) is not modified in any
  way by this plan — no shared `Cargo.toml`, no workspace.
- `desktop/src-tauri/` is a standalone Cargo project with its own
  `Cargo.toml` / `Cargo.lock`.
- The window loads `https://screen-share-h0rb5w.fly.dev/` exactly — no
  bundled/local frontend assets are ever shown to the user.
- Target platform for this plan: Linux (WebKitGTK) only. Do not add
  Windows-specific code or config.
- Closing the window (the X button) must hide it, not quit the app.
  Quitting only happens via "Sair" in the tray menu.
- No installers, code signing, or auto-update in this plan.
- The app icon is a placeholder (a solid-color square) — final branding is
  explicitly out of scope.
- There is no browser-automation test harness for this layer (consistent
  with `CLAUDE.md`'s testing approach for `client/`); every task ends with
  a manual verification checklist instead of automated tests.

- [ ] **Step 7: Generate a placeholder app icon**

There's no final branding yet (out of scope per the design spec), so
generate a plain solid-color square PNG to use as a stand-in. Run this
from the repo root — it's a one-off script, not part of the crate:

```bash
python3 - <<'EOF'
import struct, zlib

def write_png(path, size, rgba):
    raw = bytearray()
    for _ in range(size):
        raw.append(0)  # filter type 0 per scanline
        raw.extend(rgba * size)
    compressed = zlib.compress(bytes(raw), 9)

    def chunk(tag, data):
        return (struct.pack(">I", len(data)) + tag + data +
                struct.pack(">I", zlib.crc32(tag + data) & 0xffffffff))

    with open(path, "wb") as f:
        f.write(b'\x89PNG\r\n\x1a\n')
        f.write(chunk(b'IHDR', struct.pack(">IIBBBBB", size, size, 8, 6, 0, 0, 0)))
        f.write(chunk(b'IDAT', compressed))
        f.write(chunk(b'IEND', b''))

write_png("desktop/src-tauri/app-icon.png", 1024, bytes([0x33, 0x66, 0x99, 255]))
EOF
```

Verify: `file desktop/src-tauri/app-icon.png` reports `PNG image data,

### Task 2: System tray icon, close-to-hide, and quit

**Files:**
- Modify: `desktop/src-tauri/src/main.rs`

**Interfaces:**
- Consumes: the `"main"` window label and the bundled default icon set up
  in Task 1's `tauri.conf.json`.
- Produces: nothing consumed by further tasks — this is the last task in
  this plan.

- [ ] **Step 1: Replace `desktop/src-tauri/src/main.rs` with the full shell**

```rust
use tauri::menu::{MenuBuilder, MenuItemBuilder};
use tauri::tray::{MouseButton, MouseButtonState, TrayIconBuilder, TrayIconEvent};
use tauri::{Manager, WindowEvent};

fn main() {
    tauri::Builder::default()
        .setup(|app| {
            let show = MenuItemBuilder::with_id("show", "Abrir").build(app)?;
            let quit = MenuItemBuilder::with_id("quit", "Sair").build(app)?;
            let menu = MenuBuilder::new(app).items(&[&show, &quit]).build()?;

            TrayIconBuilder::new()
                .icon(app.default_window_icon().unwrap().clone())
                .menu(&menu)
                .on_menu_event(|app, event| match event.id().as_ref() {
                    "show" => {
                        if let Some(window) = app.get_webview_window("main") {
                            let _ = window.show();
                            let _ = window.set_focus();
                        }
                    }
                    "quit" => {
                        app.exit(0);
                    }
                    _ => {}
                })
                .on_tray_icon_event(|tray, event| {
                    if let TrayIconEvent::Click {
                        button: MouseButton::Left,
                        button_state: MouseButtonState::Up,
                        ..
                    } = event
                    {
                        let app = tray.app_handle();
                        if let Some(window) = app.get_webview_window("main") {
                            let _ = window.show();
                            let _ = window.set_focus();
                        }
                    }
                })
                .build(app)?;

            Ok(())
        })
        .on_window_event(|window, event| {
            if let WindowEvent::CloseRequested { api, .. } = event {
                let _ = window.hide();
                api.prevent_close();
            }
        })
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

- [ ] **Step 2: Run it and verify manually**

```bash
cd desktop/src-tauri && cargo tauri dev
```

Manually confirm:
- A tray icon appears in the system tray/status area once the app starts.
- Clicking the window's X button hides the window (it disappears from the
  taskbar) but the process keeps running — if you had a screen share
  active, it keeps running too, and anyone watching from a browser
  doesn't see it drop.
- Left-clicking the tray icon, or choosing "Abrir" from its menu, brings
  the window back with its previous state intact (still in the same
  room).
- Choosing "Sair" from the tray menu actually ends the process (it
  disappears from `ps aux | grep screen-share-desktop` and the tray icon
  goes away).

Stop the dev process once confirmed (via "Sair" from the tray, or Ctrl+C
if still visible in the terminal).

```bash
git commit -m "feat(desktop): add tray icon with close-to-hide behavior"
```
